MEDI HABARI - TOLEO LILILOBORESHWA

1. Extract folder hili.
2. Fungua folder MEDI-HABARI kwenye VS Code.
3. Fungua index.html kwa Live Server.

Marekebisho: menu ina SVG icons halisi na links zake; menu inaonekana vizuri kwenye simu na desktop; kategoria zina habari 3 za majaribio; habari mpya zimewekwa kwenye section moja yenye habari moja kubwa na habari ndogo zinazofuata; ticker ina lebo MPYA; footer ina maandishi meupe; ukurasa wa magazeti unaonyesha kurasa za A4 kwa mpangilio wa juu kwenda chini; font ni Arial.

Kumbuka: Admin login ya majaribio inahitaji kuunganishwa na huduma ya uthibitishaji (mfano Firebase) ili iwe login ya uzalishaji.
